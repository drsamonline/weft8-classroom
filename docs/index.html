How a computer
actually works.

Not a simulation of a lesson about computers — a computer. Sixteen registers, four flags, twenty-seven instructions, and no if statement, so the student builds one. Every exercise starts incomplete: the machine runs, does something, and the class can see exactly what is missing.

What makes it teachable

  • The starter is wrong on purpose. Running it is not a failure, it is the question — and the check says which register held the wrong value and what was expected.
  • No partial credit. The machine has no partial answers, so the tick means the program is right, not that it looks right.
  • Offline, one file, no accounts. A classroom with no internet and a decade-old laptop can run the whole lesson.
  • Built on the Loom. The machine is weft8.js from app-jacquard, byte for byte — so a student who finishes these eight can open Jacquard or the puzzle set and it is the same computer.
